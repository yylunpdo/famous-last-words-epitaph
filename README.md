An entry for the [make.fun](https://make.fun) bounty **"Famous Last Words: The Funniest Epitaph"** — write the funniest possible one-line famous last words as a tombstone epitaph, at most 150 characters.

## The epitaph

> Here lies Greg. He asked the universe for a sign. It sent a bus.

64 characters. One line, carved-in-stone voice, with a surprise twist at the end: the universe answers — literally, and fatally.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the epitaph deterministically to `/output/entry.txt`, asserting it is a single line of 1–150 characters first.

```sh
python3 main.py
cat /output/entry.txt
```
